## 仕様
- 仕上がりサイズ：A5横 210×148mm
- データサイズ：216×154mm（上下左右に塗り足し3mm）
- 文字は仕上がり線から3mm以上内側に配置
- フォント：PDFに埋め込み済み（Shippori Mincho／Noto Sans JP）
- カラー：RGBで作成。CMYK変換は印刷所にて対応をお願いします

## 印刷所へのお願い
- **表面左側の「講師写真」枠に、講師写真を配置してください。**
  枠は塗り足しを含めて左端から84mm（仕上がりでは左端から81mm）、上下いっぱいです。
  点線と「講師写真（印刷所にて配置）」の文字は、写真で覆って消してください。
