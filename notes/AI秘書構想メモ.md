# AI秘書構想メモ

## コンセプト

頭の中にあるイメージ：それぞれの分野の「専門家AI」を作る。

- 専門家AI同士が会議をして、ベストな方法を考え、構築し、提案してくる
- 提案を受けて、自分（人間）が判断し、また指示を出す
- この専門家たちのトップをまとめる「リーダー役」として、全体像を把握する「AI秘書」を置く

イメージ図（ラフ）：

```
[専門家AI-1] ─┐
[専門家AI-2] ─┼─→ 会議・検討 ─→ AI秘書（リーダー） ─→ 提案 ─→ 自分（判断・指示）
[専門家AI-3] ─┘                                            │
        ↑____________________________ 指示を受けて各専門家に展開 ___________________________|
```

## 想定される役割分担

- **専門家AI**：それぞれの専門領域（例：執筆、相続実務、マーケティング、経理など）に特化して検討・実行する
- **AI秘書（リーダー）**：
  - 専門家AIたちの議論・検討結果を集約する
  - 全体像（プロジェクト横断の状況）を把握する
  - 判断に必要な形に整理して自分に提案する
  - 自分の判断・指示を、各専門家AIに展開する窓口になる
