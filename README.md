# tsunagusouzoku

書籍『もめない相続は人間関係が10割』の執筆資料です。
このリポジトリはそのまま **Obsidian の保管庫（Vault）** として開けるように整理しています。

## Obsidian で開く方法

### パソコン（Windows / Mac）
1. GitHub の「Code」→「Download ZIP」でダウンロードして解凍する（または `git clone`）。
2. Obsidian を起動 →「保管庫としてフォルダを開く」→ 解凍したフォルダ（`tsunagusouzoku`）を選ぶ。
3. 左の一覧から **`ホーム`** を開くと、全資料と各章への入口が表示されます。

### 常に最新を同期したい場合
Obsidian のコミュニティプラグイン **Obsidian Git** を入れると、GitHub の更新を Obsidian 内から取り込めます（iPhone / Android でも利用可）。

## フォルダ構成

```
ホーム.md                  … 入口（章ごとの対応表つき）
manuscript/
  本文原稿.md              … 書き下ろしフル原稿
  構成案.md                … 構成案＋具体事例補足版
  エピソード候補メモ.md     … 章別エピソード候補（元メルマガへリンク）
  メルマガアーカイブ.md     … メルマガ112通の一覧
  メルマガ/                … メルマガ1通＝1ノート（日付・タグ付き）
.obsidian/                 … Obsidian の共通設定
```
