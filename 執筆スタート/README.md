## フォルダの使い方

| フォルダ | 入れるもの |
|----------|-----------|
| `00_ネタ受信箱/` | 章が決まっていない思いつき・現場での気づき。まずここに放り込む |
| `01_はじめに` 〜 `10_おわりに` | `原稿.md`＝本文（企画書の見出し入り）／`素材メモ.md`＝使うエピソード（初稿からの流用候補つき） |
| `90_出版社とのやりとり/` | 企画書・編集者との打ち合わせ記録・締切 |
| `91_校正・修正履歴/` | 校正指示と修正の記録 |
| `99_没原稿・保留/` | 削った文章・見送ったエピソード（消さずに保管） |

### 流れ
1. 気づき・エピソード → `00_ネタ受信箱/ネタ帳.md`
2. 使う章が決まったら → 各章の `素材メモ.md` へ移す
3. 本文として書いたら → 各章の `原稿.md` の該当見出しの下へ
4. 削った部分 → `99_没原稿・保留/` へ
