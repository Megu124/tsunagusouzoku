# 執筆スタート ｜『もめない相続は人間関係が10割』

出版決定（2026年11月）を受けて、ここから書き溜める原稿・素材を蓄積していくフォルダです。
これまでの準備資料（構成案・エピソード候補・メルマガアーカイブ・初稿）は `../manuscript/` にそのまま残してあります。

## フォルダの使い方

| フォルダ | 入れるもの |
|----------|-----------|
| `00_ネタ受信箱/` | 章が決まっていない思いつき・現場での気づき。まずここに放り込む |
| `01_〜11_` 各章 | `原稿.md`＝その章の本文／`素材メモ.md`＝その章で使うエピソード・言葉 |
| `90_出版社とのやりとり/` | 編集者との打ち合わせ記録・締切・決定事項 |
| `91_校正・修正履歴/` | 校正指示と修正の記録 |
| `99_没原稿・保留/` | 削った文章・見送ったエピソード（消さずに保管） |

### 流れ
1. 気づき・エピソード → `00_ネタ受信箱/ネタ帳.md`
2. 使う章が決まったら → 各章の `素材メモ.md` へ移す
3. 本文として書いたら → 各章の `原稿.md` へ
4. 削った部分 → `99_没原稿・保留/` へ
